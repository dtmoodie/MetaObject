# console_reflection

Registers `ConcreteImplementation` (obj.cpp) with the MetaObject factory, prints its static info (`PrintHelp`) and reflection info, then constructs it through the factory and calls `foo()`.

The output of this example should be as follows:

````
Concrete PrintHelp() called


ExampleInterface ***** ConcreteImplementation 
----------- Params ------------- 
integer_Param    C [int]
    0
float_Param      C [float]
    0.0
input_int_Param  O [int]
output_int_Param [int]
    0

Concrete implemtnation of foo called
````

Notes on the format (generated by `IMetaObjectInfo::Print` in `modules/object/src/MetaObject/object/MetaObjectInfo.cpp`):

- The flag letters after each name come from the param's reflection flags (`ParamReflectionFlags`, `modules/core/src/MetaObject/core/detail/Enums.hpp`): `C` = control param (`PARAM`), `I` = `kINPUT`, `O` = `kOUTPUT`. The `INPUT` macro currently registers its reflection flag as `kOUTPUT`, and the `OUTPUT` macro registers none — both are mid-Subscriber/Publisher-refactor, so the letters in the block above reflect the code as written; re-run the example after a full build and update this block if they have since changed.
- The `INPUT` member type is `TSubscriberPtr<int>::Input_t` (`const int*`); `typeToName` renders the type, so its exact spelling follows the `TypeTable` registration.
